# 대기오염 평균농도 대시보드

발전기·호기별 월평균 대기오염 농도와 허용기준 대비 수준을 탐색하는 Streamlit 대시보드입니다.

## 주요 기능

- 기간, 발전기명, 호기명, 오염물질 필터
- 평균농도와 허용기준 대비 비율 핵심 지표
- 월별 추이 및 발전기·호기 비교
- 기준 초과 관측과 비율 분포 확인
- 상세 데이터 검색 및 CSV 다운로드
- CSV 스키마, 날짜, 숫자, 중복 키 검증

## 실행 방법

현재 프로젝트에는 가상환경과 의존성이 구성되어 있습니다. 다음 명령으로 바로 실행할 수 있습니다.

```powershell
.\.venv\Scripts\streamlit.exe run app.py
```

새 환경에서 설치할 때는 Python 3.11 이상을 사용합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 `http://localhost:8501`을 엽니다. Streamlit이 사용 가능한 포트를 자동으로 선택한 경우 터미널에 표시된 주소를 사용합니다.

## 검사 방법

python -m pytest

## 데이터 교체

프로젝트 루트의 `대기오염물질_배출량_2022-2025_결측치보간_병합.csv`를 같은 이름과 컬럼 구조의 새 파일로 교체한 뒤 앱을 다시 실행합니다. 앱은 파일 수정 시각을 기준으로 캐시를 갱신합니다.

필수 컬럼과 데이터 해석은 [데이터 설명서](./데이터_설명서.md), 화면 및 지표 설계는 [개발 계획서](./대기오염_대시보드_개발_계획서.md)를 참고하세요.

## 해석상 주의사항

이 데이터는 총배출량이 아니라 월평균 농도 자료입니다. 화면의 ‘기준 초과 관측’은 같은 행의 평균농도와 허용기준을 비교한 데이터 탐색 결과이며 법적 위반 판정을 뜻하지 않습니다.
